<p align="center">
  <b>📄 Analyze &nbsp; • &nbsp; 🎯 Match &nbsp; • &nbsp; 📊 Score &nbsp; • &nbsp; 💡 Improve &nbsp; • &nbsp; 🤖 Practice</b>

An AI-powered resume analysis application that compares a resume with a target job description and provides useful career insights.

### ✨ What It Does

| 📄 Resume | 🎯 Job Matching | 📊 Analysis |
|:---:|:---:|:---:|
| Upload PDF | Compare with JD | Resume Score |
| Extract Skills | Match Skills | ATS Analysis |
| Analyze Details | Find Missing Skills | AI Suggestions |

| 📚 History | 🤖 AI Interview | 🎤 Practice |
|:---:|:---:|:---:|
| Save Analyses | Generate Questions | Voice Answers |
| Search Resumes | Resume-Based Questions | Listen to Questions |
| Filter by Score | Job-Based Questions | Interactive Practice |
