An AI-powered resume analysis application that compares resumes with job descriptions and provides useful career insights.

### ✨ Features

- 📄 Resume PDF Upload
- 📊 Resume Score
- 🎯 ATS Analysis
- ✅ Matched Skills
- ❌ Missing Skills
- 💡 AI Suggestions
- 📚 Resume Analysis History
- 🔎 Search & Filter
- 🤖 AI Interview Questions
- 🎤 Voice Answer
- 🔊 Listen to Questions
- 🗄️ MySQL Database
- 🔌 REST API
